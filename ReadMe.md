# Bulldozer Price Prediction 🚜



## Project Overview

This project uses machine learning to predict the sale prices of bulldozers based on historical auction data.



The goal is to build a regression model that predicts bulldozer prices as accurately as possible.



## Problem Statement

Predict the sale price of a bulldozer using its characteristics and historical sales information.



## Tools \& Technologies

- Python

- Jupyter Notebook

- Pandas

- NumPy

- Matplotlib

- Scikit-learn



## Machine Learning Model

- Random Forest Regressor

- Hyperparameter tuning

- Regression model evaluation



## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)

- Root Mean Squared Logarithmic Error (RMSLE)

- R² Score



### Validation Results



| Metric | Training | Validation |

|---|---:|---:|

| MAE | 2,503.05 | 5,872.13 |

| RMSLE | 0.1273 | 0.2431 |
